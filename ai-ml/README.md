# Artificial Intelligence & Machine Learning

## What problem do AI and ML solve?

Traditional programs follow rules written by people. Some tasks—recognizing patterns, understanding language, classifying images, or predicting outcomes—are difficult to describe with complete hand-written rules. Machine learning uses data and optimization to fit a model that performs a task.

## Why were these ideas created?

Researchers explored ways for computers to perform tasks associated with intelligence. Machine learning developed methods for systems to improve task performance from examples rather than relying only on explicitly programmed rules. Deep learning uses multi-layer neural networks and large-scale computation to learn representations.

## How to study AI/ML

1. Define the task and success metric.
2. Understand the data and its limitations.
3. Choose a model and understand its assumptions.
4. Learn the mathematical operations involved.
5. Trace training: forward pass, loss, gradients, optimizer, parameter updates.
6. Separate training from inference.
7. Evaluate on data not used for training.
8. Inspect failure cases, bias, cost, and latency.

## Topics

- Linear algebra, calculus, probability, statistics
- Data preparation, features, and datasets
- Supervised, unsupervised, and reinforcement learning
- Linear/logistic regression and classical ML
- Neural networks, activations, loss, and backpropagation
- Tokenization, embeddings, and language modeling
- Transformers, attention, and positional information
- Training, fine-tuning, inference, and evaluation
- Retrieval-augmented generation and vector search
- Agents, tool use, and system evaluation
