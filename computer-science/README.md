# Computer Science

This section covers the foundations underneath software: how information is represented, how programs execute, and how hardware and operating systems provide resources to applications.

## Why study this?

When an application behaves unexpectedly, the cause may be below the framework: memory layout, CPU execution, processes, threads, scheduling, files, or I/O. These foundations help replace guesswork with a model of what the machine is doing.

## Topics

- Programming language fundamentals and runtime execution
- Number systems and data representation
- Computer architecture: CPU, memory, cache, instruction execution
- Operating systems: processes, threads, scheduling, memory, files, system calls
- Concurrency fundamentals

For every topic ask: What problem does this mechanism solve? Why is it designed this way? What happens step by step? What are its costs and failure modes?

**Labs:** inspect a process, measure memory, compare sequential and concurrent work, or trace a system call.
